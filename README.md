# Greenvale: After the Fall — RPGJS V2.2

RPGJS v5 is the permanent engine base.

RPGJS owns movement, mobile input, collision, maps, character animation, action combat, AI, skill, inventory, equipment, hotbar, save/UI and future multiplayer.

Greenvale owns story, quests, dungeons, pets, forge, loot/rarity, survival, farming, base and bosses.

## Netlify
- Build command: `npm run build`
- Publish directory: `dist`
- Node 22
- `RPG_TYPE=rpg`
